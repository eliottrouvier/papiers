## 🗂️ Structure d'un Papier

Chaque papier dispose de son propre dossier chronologique au format `YYYY_nom-du-papier` :

```text
YYYY_nom-du-papier/
├── paper.pdf    # PDF original de la publication
├── notes.md     # Analyse, résumé et notes de lecture
└── main.py      # Code d'expérimentation et reproduction
```

Pour initialiser un nouveau papier :
```bash
cp -r _template YYYY_nom-du-papier
```
